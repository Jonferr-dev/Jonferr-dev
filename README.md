## 🧠 O que eu faço

- 🔄 **Pipelines ETL/ELT:** ingestão, transformação e carga de dados com Python, SQL e Pandas.
- ⏱️ **Orquestração:** fluxos de dados agendados e monitorados com Apache Airflow (DAGs).
- ☁️ **Cloud:** Data Lake no Amazon S3, bancos gerenciados no Amazon RDS e análises no Google BigQuery.
- 🗄️ **Bancos de Dados:** modelagem de dados e consultas SQL em PostgreSQL e MySQL.

- ✅ **Qualidade de Dados:** validação, tratamento e documentação dos processos.
