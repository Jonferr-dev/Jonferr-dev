## 🧠 O que eu faço

- 🔄 **Pipelines ETL/ELT:** ingestão, transformação e carga de dados com Python, SQL e Pandas.
- 🔌 **Integração de APIs REST:** consumo de APIs externas como OpenWeatherMap e TMDB com Python e Requests.
- ⏱️ **Orquestração:** fluxos de dados agendados e monitorados com Apache Airflow e DAGs.
- ☁️ **Cloud:** Data Lake no Amazon S3, bancos gerenciados no Amazon RDS, AWS Glue e análises no Google BigQuery.
- 🗄️ **Bancos de Dados:** modelagem de dados e consultas SQL em PostgreSQL e MySQL, além de bancos não relacionais.
- 📁 **Formatos de Dados:** armazenamento estruturado em CSV, JSON e Parquet.
- 🐳 **Containerização:** ambientes reproduzíveis com Docker em Linux Ubuntu e WSL.
- ✅ **Qualidade de Dados:** validação, tratamento, investigação de falhas e documentação dos processos.
- 📊 **Visualização:** dados prontos para análise e dashboards no Power BI.

### 🌦️ [Pipeline de Dados Climáticos com Apache Airflow](https://github.com/Jonferr-dev/projeto_pipeline_etl_weather_data)
Pipeline orquestrado com Apache Airflow que consome a API OpenWeatherMap. O armazenamento local foi migrado para a AWS: dados brutos em Data Lake no Amazon S3 e dados tratados em banco relacional no Amazon RDS. A solução roda em containers Docker em Linux, com resolução de problemas de DAGs, caminhos de arquivos e rede entre containers.

`Python` `Apache Airflow` `AWS S3` `AWS RDS` `Docker` `Linux`

### 🎬 [Plataforma de Consulta e Análise de Filmes - API TMDB](https://github.com/Jonferr-dev/PROJETO_ETL_FILMES)
Pipeline ETL para extração, transformação e carga de dados cinematográficos da API TMDB, com modelagem de tabelas e persistência em PostgreSQL. Consultas SQL organizam os dados para análise no Power BI.

`Python` `SQL` `PostgreSQL` `Power BI` `Docker` `Linux Ubuntu` `WSL`
